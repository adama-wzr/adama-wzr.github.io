The dataset linked contains the following:
* 40,000 binary 2D structures (128 x 128 pixels)
* Dataset can be augmented by rotating and flipping the color scheme, except for QSGS
* Total 130,000 simulations at each thermal conductivity ratio
* Four thermal conductivity rations considered: 10, 50, 100, 341.7 (Al vs. Water)
* Total of 520,000 effective thermal conductivity simulation results

For more details, visit the Mendeley Data page.
