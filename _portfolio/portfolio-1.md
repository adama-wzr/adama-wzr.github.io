The characterization of phase-size distribution is a property of intereset across several different fields of study. This algorithm fills this gap, by providing a scalable solution to phase-size estiamtion. The software is supposed to be a plug-and-play solution to phase size estimation, hence computational efficiency and simplicity are cornerstones of this project. This code has been tested on 2D and 3D structures up to 1000<sup>3</sup> voxels, without showing any signs of trouble.

* The ED-cPSD software and code are available on [GitHub](https://github.com/adama-wzr/ED_cPSD). Additional documentation and examples are also provided.
* Please refer to the original open-souce publication on [SoftwareX](https://www.sciencedirect.com/science/article/pii/S2352711025001785).

If there are any questions or interest in the software, please reach out to one of the corresponding authors. There is a plan for continuous development of this software, and this plan will be posted whenever there is a more concrete plan (scope and timeline) for development.
